# 寰球智投 · 客户端功能与布局改进路线图

> 编写日期：2026-11-18 · 基线版本 v2.3.1 · 对标对象：东方财富 / 同花顺客户端
> 本文件是后续版本的需求基线：每完成一项，在「实施状态」里更新状态与版本号。

---

## 一、目标与边界

**目标**：在现有技术栈（零 npm 依赖、Node 单进程、原生 SPA + ECharts、免费公开行情接口、sqlite/json 双存储、本机 + NAS 双部署）不变的前提下，对标专业行情终端补齐核心功能缺口、理顺信息架构、降低单体前端维护风险。

**不做的事（合规与成本红线）**：

- 不做实盘下单、账户托管——本工具是行情与策略研究终端，不持有交易资质；
- 不接 Level-2 十档、逐笔委托、龙虎榜逐笔等付费数据；
- 北向资金不做「盘中实时净流入」（2024-08 起交易所已取消该披露，任何免费源给出的盘中数字都不可信）；
- 所有评分、筛选、预警继续标注「规则模型 / 估算口径，非投资建议」。

### 阶段 2 · P1 数据中心（预计 v2.5.x）

1. **龙虎榜**：新增 `lib/datacenter.js` 封装东财 datacenter 报表；`/api/longhu`、`/api/longhu/stock`；个股详情新增「龙虎榜」页签；先做网络探测，失败明确降级。
2. **财经日历 / 数据中心**：新股申购、可转债申购、限售解禁、分红送转、融资融券余额；新视图「数据中心」；自选股命中解禁/分红时在自选页提示。
3. **条件选股器**：`/api/screener` 接收条件数组服务端过滤 clist 全量快照；支持保存方案；结果一键加自选/加预警。
4. **服务端预警引擎**：schema 升 v3 新增 `alerts` 表（用户隔离、规则 JSON、启用状态、最近触发）；盘中按分钟评估并走 `push.js` 四通道；前端加「云端预警」开关与同步状态。
5. **港股个股 / 可转债**：搜索索引扩港股 secid 与转债代码；新增可转债列表（价格/溢价率/评级/剩余年限）；复用个股弹窗并按市场隐藏不适用字段。

### 阶段 3 · P2 大模块

轻量 F10（概况/财务/股东/分红，作为个股详情页签）、北向数据（合规版，仅季度持股与盘后活跃股）、模拟交易 + 信号留痕（虚拟账本 + 策略命中率）、PWA（manifest + Service Worker，同时根治发版缓存）、移动端底部 5 Tab（行情/市场/策略/自选/我的）、资讯升级（个股相关新闻/公告聚合与分类过滤）。

### 阶段 4 · P3 候选（暂不承诺）

画线与图表标注、自定义看板拖拽、浅色主题（先 CSS 变量化）、SSE 替代轮询（收益有限需单独立项）、多窗口盯盘屏。

## 五、变更清单与约束

**新增 API**：`/api/kline?fqt=`（阶段 1）；`/api/longhu`、`/api/longhu/stock`、`/api/calendar`、`/api/screener`、`/api/convertibles`、`/api/alerts`（阶段 2）。
**schema 版本**：阶段 1 不动库结构；阶段 2 升 v3（alerts），模拟交易再升 v4；一律走 `lib/store.js` 版本化迁移，JSON 模式提供等价降级。
**版本与缓存**：每版本同步 9 处版本串 + `data/changelog.json` 新条目（最新的放最前），并规避历史踩过的发版缓存陷阱。
**文案编码**：Windows PowerShell 5.1 下直接 `Get-Content/Set-Content` 读写 UTF-8 中文源文件会损坏中文，改动一律用编辑工具或显式 `-Encoding UTF8` 并核对编码。
**测试**：后端 `node --test test/*.test.mjs`；前端 `scripts/check-frontend-modules.mjs` 与 `test/dom-smoke.test.mjs`；新增能力补 fixtures 驱动的单测，不依赖实时外网。
